# المؤتمر العلمي الدولي الثالث — الجرائم العابرة للحدود

بوابة المؤتمر العلمي الدولي الثالث لأكاديمية السلطان قابوس لعلوم الشرطة: جلسات المؤتمر وأوراقه العلمية، تقارير رئيس الجلسة ومقررها مع مساعد ذكي («المفكّر»)، أسئلة الجمهور المباشرة، ودليل قاعات ثلاثي الأبعاد.

**Sultan Qaboos Academy for Police Sciences — 3rd International Scientific Conference on Transnational Crimes.**

| الصفحة | الرابط | لمن |
|---|---|---|
| الموقع الرئيسي | https://sqaps-conference.vercel.app | الجميع |
| طرح الأسئلة | `/qn` (و`/qn?s=N` لجلسة محددة) | الجمهور |
| دليل القاعات | `/map` (و`/map?session=N` لقاعة جلسة) | الجمهور |
| لوحة الإدارة | `/admin` | مدير المؤتمر (تسجيل دخول) |

---

## ✨ الميزات

### الجلسات
- لكل جلسة: التوقيت، المكان، رئيس الجلسة ومقررها **مع رقم هاتف كل منهما**، ورابط «عرض القاعة على الخريطة».
- جدول الأوراق البحثية: العنوان، الباحثون (اسم في كل سطر) **مع رقم هاتف تحت اسم كل باحث**، ومعاينة/تحميل الورقة والسيرة الذاتية (PDF).
- أرقام الهواتف تظهر للزوار كأزرار اتصال، ولا يعدّلها إلا مدير المؤتمر.

### تقارير الجلسة (خاصة)
- **تقرير رئيس الجلسة** و**تقرير مقرر الجلسة** في قسمين منفصلين، لكل منهما تقرير عام وتقرير لكل ورقة.
- كل تقرير يُحفظ في خانته (`session_reports.role` = `chair` | `secretary`)، ويتابعها المدير في تبويب «التقارير» جنباً إلى جنب لكل جلسة.

### المفكّر — المساعد الذكي (DeepSeek)
| رئيس الجلسة | مقرر الجلسة |
|---|---|
| التقرير الرسمي للجلسة | محضر الجلسة الرسمي |
| ملخص الورقة | ملخص الورقة |
| تقييم الورقة (8 معايير × 5 = 40) | ملخص المداخلات والنقاش |
| أسئلة للنقاش | التوصيات الموحّدة |
| قراءة مقارنة للجلسة | تنسيق المحضر |
| التوصيات الموحّدة، تنسيق التقرير، البيان الختامي للمؤتمر | |

المعرفة من ملفات المستودع لا من قاعدة البيانات: `docs/papers/…` (النص الكامل)، `docs/cv/…` (صفحة الملخص)، `docs/cards/…` (بطاقات التحليل، تُبنى بـ `npm run cards`). القوالب الرسمية في `src/lib/ai-prompts.ts`.

### أسئلة الجمهور
- صفحة `/qn` + رمز QR لكل جلسة من لوحة الإدارة.
- حد الإرسال: 5 أسئلة/دقيقة **لكل متصفح** (حتى لا يُحجب الحضور المتصلون بشبكة Wi-Fi واحدة)، وسقف 120/دقيقة لكل عنوان IP.

### دليل القاعات `/map`
- مجسّم ثلاثي الأبعاد للطابق الأرضي (three.js) بالمسارات والاتجاهات خطوة بخطوة، بحث بالقاعة أو رقم الغرفة أو **عنوان الجلسة**، ورموز QR للمداخل.
- كل قاعة تعرض جلساتها ووقتها؛ و`/map?session=N` يفتح المسار مباشرة إلى قاعة الجلسة.
- الصفحة ملف ثابت `public/map/index.html` تقرأ إعداداتها من `/api/map-config`.

### لوحة الإدارة `/admin`
| التبويب | ما فيه |
|---|---|
| بيانات الجلسة | التوقيت، المكان، **القاعة على الخريطة**، رئيس الجلسة والمقرر وهاتفاهما، الأوراق وهواتف الباحثين ورفع ملفات PDF (حفظ تلقائي) |
| محتوى الموقع | كل نصوص الموقع وعناوين الجلسات والبرنامج |
| إدارة الأسئلة | أسئلة الجمهور لكل جلسة وحذفها |
| التقارير | تقرير الرئيس وتقرير المقرر لكل جلسة جنباً إلى جنب، عرض/تنزيل/حذف |
| الخريطة | أي جلسة في أي قاعة، والخريطة بوضع المنظّمين: تحديد مكان كل قاعة وخدمة وإضافتها وحذفها |
| مشاركة / QR | رموز QR، حالة الذكاء الاصطناعي، النسخ الاحتياطي |

## 🔒 الصلاحيات

- `/admin` و`/api/admin/*` محمية بـ HTTP Basic Auth عبر `src/proxy.ts` (بيانات الدخول من `ADMIN_USER` / `ADMIN_PASSWORD` في Vercel — **لا تُكتب في الكود**، المستودع عام).
- كتابة البيانات للمدير فقط: `PUT /api/sessions/[id]`، `PUT /api/site-content`، `POST /api/papers/upload`، `PUT /api/map-config`، `DELETE /api/questions` (`src/lib/admin-auth.ts`). المتصفح يعيد إرسال تسجيل دخول `/admin` تلقائياً، فلا تحتاج لوحة الإدارة أي تعديل.
- عامة: قراءة بيانات الجلسات والخريطة، إرسال الأسئلة، ومحرر التقارير والمفكّر في الصفحة الرئيسية.

## 🛠️ التقنيات

- **Next.js 16** (App Router) + **TypeScript 5** + **Tailwind CSS 4** + **Framer Motion**
- **Prisma 6** + **PostgreSQL على Neon** (us-east-1)
- **DeepSeek** للمفكّر (`src/lib/ai.ts`)
- **three.js** لدليل القاعات
- النشر على **Vercel** (فريق `sqps3`، مشروع `sqaps-conference`)

### قاعدة البيانات (`prisma/schema.prisma`)
| الجدول | المحتوى |
|---|---|
| `track_sessions` | بيانات الجلسة + `chairPhone` / `secretaryPhone` / `mapHall` |
| `research_papers` | الأوراق + `phone` (رقم لكل باحث بنفس ترتيب الأسماء) |
| `session_reports` | تقارير الرئيس والمقرر (`role`) — الفهرس الفريد `(trackId, paperSlot, role)` **NULLS NOT DISTINCT** |
| `paper_files` | ملفات PDF المرفوعة (base64) |
| `questions` | أسئلة الجمهور |
| `site_content` | نصوص الموقع (مفتاح/قيمة) |
| `settings` | إعدادات أخرى، منها `map.config` (قاعات وخدمات الخريطة) |
| `ai_evaluations` | تقييمات المفكّر المخزّنة (خاصة) |

> ⚠️ فهرس `session_reports` أُنشئ يدوياً بـ `NULLS NOT DISTINCT` (يمنع تكرار التقرير العام عند الحفظ المتزامن). Prisma لا يعرف هذا الخيار، فلا تشغّل `npm run db:push` على قاعدة الإنتاج — طبّق تغييرات الجداول بـ SQL مباشر.

## 🔑 متغيرات البيئة

| المتغير | مطلوب | الوصف |
|---|---|---|
| `DATABASE_URL` | ✅ | رابط PostgreSQL (Neon، المضيف `-pooler`) |
| `DEEPSEEK_API_KEY` | ✅ للمفكّر | مفتاح DeepSeek |
| `DEEPSEEK_MODEL` | ❌ | الافتراضي `deepseek-chat` |
| `ADMIN_USER` / `ADMIN_PASSWORD` | ✅ | تسجيل دخول لوحة الإدارة (بدونهما تُقفل الإدارة) |
| `TELEGRAM_BOT_TOKEN` / `TELEGRAM_CHAT_ID` | ❌ | إشعارات رسائل الدعم |
| `CALLMEBOT_API_KEY` / `CALLMEBOT_PHONE` | ❌ | إشعارات واتساب |
| `CONTACT_EMAIL` | ❌ | بريد التواصل |

انظر `.env.example`.

## 🚀 التشغيل والنشر

```bash
bun install
cp .env.example .env    # ثم عدّل القيم
bun run dev             # http://localhost:3000
```

> المشروع داخل OneDrive: لا تثبّت `node_modules` فيه — ابنِ واختبر في نسخة خارجه (`git clone`).

**النشر:** كل `git push` إلى `main` على `github.com/innoIII/sqaps-conference` يُنشر تلقائياً على Vercel. الفروع الأخرى تُنشر كنسخ تجريبية (Preview) محمية.

**مساحة الدوال (Functions Storage — 10 GB في الخطة المجانية):** كل نسخة نشر محفوظة تُحتسب. `next.config.ts` يستبعد محركات Prisma غير المستخدمة (حجم الدالة ~9 MB بدل 32.5 MB، أي ~52 MB لكل نشر). احذف النسخ القديمة من Vercel دورياً.

**ملاحظة `.gitignore`:** فيه `*.png` — أي صورة PNG جديدة خارج `public/logo/` و`src/app/` لن تُرفع.

## 🧪 اختبار التحمل

`scripts/loadtest.mjs` يحاكي الاستخدام الفعلي (يكتب على جلسة اختبار رقم 49 — احذف بياناتها بعده):

```bash
node scripts/loadtest.mjs browse  https://<الرابط> 20 60   # 20 زائراً لمدة 60 ثانية
node scripts/loadtest.mjs saves   https://<الرابط> 20      # 20 حفظاً متزامناً للتقارير
node scripts/loadtest.mjs ai      https://<الرابط> 20      # 20 طلباً للمفكّر في نفس اللحظة
node scripts/loadtest.mjs aiheavy https://<الرابط> 20      # 20 تقريراً رسمياً/محضراً كاملاً
```

نتائج 21 أكتوبر 2026:

| الاختبار | النتيجة |
|---|---|
| 20 زائراً لمدة دقيقة (2,475 طلباً) | ✅ 100% نجاح، أغلب الردود ≈ 0.4 ثانية |
| 40 زائراً | ✅ لا أخطاء من الخادم |
| 20 حفظاً متزامناً للتقارير (×4 جولات، 200 عملية) | ✅ لا أخطاء، لا تكرار، كل تقرير في خانته |
| 20 سؤالاً للمفكّر معاً | ✅ 20/20، خلال 9–15 ثانية |
| 20 تقريراً رسمياً/محضراً كاملاً معاً | ✅ 20/20، خلال 14–20 ثانية (الحد 120) |
| 20 شخصاً على شبكة Wi-Fi واحدة يرسلون أسئلة | ✅ لا حجب |
